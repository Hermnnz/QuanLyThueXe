# Dữ liệu demo

Dữ liệu demo cho phân hệ Quản lý đội xe và Bảo dưỡng (Fleet & Maintenance) nằm trực tiếp tại:
- Danh sách xe máy điện & Dòng xe: `custom_addons/motorbike_fleet_management/data/vehicle_demo.xml`
- Phiếu dịch vụ & Bảo dưỡng mẫu: `custom_addons/motorbike_fleet_management/data/service_demo.xml`

Module thứ 5 (`motorbike_rental_demo`) đã được dọn dẹp để đảm bảo đồ án tuân thủ đúng cấu trúc 4 module cốt lõi theo yêu cầu của nhóm trưởng.
